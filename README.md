# Girl Call Center — prototype Mini App

Cette version est préparée pour être publiée comme prototype statique sur GitHub Pages.

## Important

Cette version est une démonstration de l'interface uniquement :
- elle ne réalise aucun paiement ;
- elle ne débite pas réellement un compte ;
- elle ne contient pas encore le transport audio temps réel ;
- elle ne contient pas de clés API.

La version complète nécessitera un backend sécurisé, Telegram Stars, une base de données et un fournisseur de voix/IA.

## Publication GitHub Pages

1. Envoyer tous les fichiers de ce dossier à la racine du dépôt GitHub.
2. GitHub → Settings → Pages.
3. Source : Deploy from a branch.
4. Branch : main / root.
5. Save.
6. GitHub fournira une URL HTTPS.

Cette URL servira ensuite de base pour la Mini App Telegram.
